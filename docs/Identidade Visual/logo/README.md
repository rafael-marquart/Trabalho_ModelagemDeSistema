# Logos AcessaVagas

Três variações independentes em SVG, vetoriais e legíveis/editáveis como XML.

- `Logo-Simbolo.svg`: apenas o símbolo de acessibilidade, com os três traços lilás.
- `Logo-Simbolo-e-Nome.svg`: símbolo e nome AcessaVagas.
- `Logo-Completo-com-Slogan.svg`: símbolo, nome e frase “Acesso que transforma.”

Fundo branco. Paleta: roxo `#35106F`, violeta `#7134BE`, lilás. Estes SVGs são ativos vetoriais separados para uso no projeto.
